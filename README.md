# MobiDziennikCiemnyMotyw
Dodatek do przeglądarek bazowanych na Chromium dodający ciemny motyw dla strony mobidziennik.pl z easter eggami.

## Instalacja
1. Przejdź na stronę ["releases"](https://github.com/dawutheuwad/MobiDziennikCiemnyMotyw/releases)
2. Pobierz zawarty tam plik .zip
3. Wypakuj plik .zip do nowego folderu.
4. Otwórz w przeglądarce stronę chrome://extensions
5. Uruchom tryb dewelopera (prawy górny róg)
6. Wciśnij przycisk "Załaduj rozpakowane (Load unpacked)"
7. Wybierz folder do którego rozpakowałeś(aś) plik .zip
8. Gotowe!
